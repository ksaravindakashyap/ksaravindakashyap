## 🚀 Selected Projects

### **DevInfra OpsHub — GitOps Control Panel**
A GitOps-driven control panel for automated preview deployments.  
Built per-PR preview environments with secure configuration management, CI/CD pipelines, and integrated observability.

### **MediSync — IoT & ML Medication Adherence**
An IoT + ML system for monitoring medication adherence using image recognition and sensor data.  
This work was published at **IEEE CSITSS 2023**.

### **Cross-Schema NL2SQL System**
A natural-language-to-SQL system that works across heterogeneous databases and schemas.  
Designed to reduce schema hallucinations using schema-aware planning and human feedback.

An AI-powered healthcare pipeline for automated ICD-10 prediction.  
Built with OCR, embeddings, and a modular inference service focused on reliability and data privacy.

### **LRU Cache (C++20)**
